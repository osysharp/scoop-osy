# Scoop bucket for Osy#

```powershell
scoop bucket add osy https://github.com/osysharp/scoop-osy
scoop install osy
scoop update osy
```

Installs `osy` and `osyrin`, the Osy# toolchain, from the releases on [osysharp/cli](https://github.com/osysharp/cli/releases).
The manifest is generated by the toolchain's release and pinned to the archive's SHA-256; do not edit it by hand.
